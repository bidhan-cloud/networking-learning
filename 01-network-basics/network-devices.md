# Network Devices

## Switch

A switch connects devices inside the same network.

Examples:
- Laptop
- Printer
- Server

Switch forwards traffic using MAC addresses.

---

## Router

A router connects different networks.

Example:

Home Network -> Router -> Internet

My gateway:

192.168.80.1

Command:

ip route

---

## Firewall

A firewall allows or blocks traffic.

Examples:

Allow:
- Port 443

Block:
- Port 22

Firewall acts like a security guard.

---

## Real Example

When I open google.com:

Laptop -> Switch -> Router -> Internet -> Google Server
