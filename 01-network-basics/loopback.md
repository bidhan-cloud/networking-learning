# LOOPBACK

## What is it?

Loopback is when a device communicates with itself.

Default loopback IP:

127.0.0.1

## Why do we use it?

It helps test network services on the same machine.

## Real example

When I ping 127.0.0.1, my computer talks to itself.

## What I learned

Loopback helps me test networking inside my own system.
