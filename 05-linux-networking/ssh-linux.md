# SSH IN LINUX

## What is it?

SSH lets me securely connect to another Linux server remotely.

## Real example

ssh user@server-ip

## What happens?

My Linux system creates a secure remote connection.

## What I learned

SSH helps me manage remote servers safely.

Default port: 22

## Commands learned

- ssh localhost
- ps aux | grep ssh
- ss -tulpn | grep :22
- systemctl status ssh
- systemctl start ssh
- hostname -I

## What I learned

- SSH = Secure Shell
- Port 22 = SSH
- sshd = SSH server
- SSH allows secure remote access
